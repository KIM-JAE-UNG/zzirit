# 찌릿 점검 (tests)

앱을 고칠 때마다 아래 한 줄로 전부 확인합니다. 하나라도 실패하면 배포하지 않습니다.

```
bash tests/run-all.sh
```

| 점검 | 파일 | 하는 일 |
| --- | --- | --- |
| 서버 규칙 | `db/rules.test.mjs` | 마이그레이션을 PGlite(브라우저용 Postgres)에 올려 결제 확인, 주문 제한, 초기화, AI 검토, 계정 삭제, 아이디 로그인 규칙을 확인 |
| 지금 서버 | `db/before-reset.test.mjs` | 0001–0007b까지만 올린 지금 서버 상태에서 아이디·복구 코드·포인트가 동작하는지 확인 |
| 폰 알림 서버 | `db/push.test.mjs` | 0010을 지금 서버 상태 위에 올려 구독, 실제 일어난 일인지 확인, 한 번만 보내기, 보내는 사람 제한, Vault 키, 권한을 확인 |
| 채팅·탈퇴 서버 | `db/chat.test.mjs` | 모든 마이그레이션을 올려 전체 채팅(누가 썼는지 서버가 기록, 링크·전화번호·도배·채팅 금지), 1:1(친구만, 두 사람만 읽음), 운영자 숨기기·금지·게시판 완전 삭제, 1:1 폰 알림 확인, 회원 탈퇴(비밀번호, 연결 기기, 친구·팀 정리)를 확인 |
| 포인트·루어 서버 | `db/points.test.mjs` | 모든 마이그레이션을 올려 주간 경계(한국 시간 월요일), 서버에서 시작한 판만 기록(너무 빠르거나 게임보다 짧은 판 거부, 한 번만 사용), 주간 상금(1·2·3등 300·200·100P, 참가 20P, 1등 황금 번개, 한 번만 지급, 동점은 가장 빠른 한 번), 지갑·내역은 본인만, 장비 구매(루어·낚싯대·릴·찌, 가격은 서버, 시그니처 800~1,200P, 중복·부족 거부), 운영자 지급·무효, 탈퇴 시 삭제를 확인 |
| 라이브 서버 | `db/live.test.mjs` | 모든 마이그레이션을 올려 어군(10분마다, 일부 칸에만), 피딩타임·물때, 고기 길이 계산, 캐스팅(프로필 필요, 입질 전·한참 뒤 챔질 거부, 남의 토큰), 랜딩(등급보다 높은 어종·민물/바다 안 맞는 어종·먼바다 어종 거부, 2.5초 안 랜딩 거부), 포인트(등급별, 새 어종 +10, 하루 80P 한도), 원정(하루 5번, 절반, 전설급 없음), 가진 장비만 효과, 주간 5마리 합계·상금·황금 루어 한 번만, 운영자 무효 처리, 테이블 직접 읽기 차단 |
| 폰 알림 암호화 | `push/webpush.test.mjs` | RFC 8291 예제를 바이트 하나까지 똑같이 재현하고 VAPID 서명을 공개 키로 검증 |
| 웹사이트 | `web/run.js` | 가짜 Supabase(`web/server.js`)로 index.html을 실제 브라우저(Playwright)에서 돌려 가입·스캔·등록·게시판·팀·결제·아이디·공지·조과 카드 등을 확인 |
| Claude 페이지 | `claude/run.js` | 가짜 Claude 런타임(`claude/mock.js`)으로 artifact.html을 확인 |
| 폰 조과 등록 | `web/phone-scan.js` | 아이폰 크기·터치로 사진 → "맞나요?" → 길이 → 등록을 손가락으로 누르듯 진행. 등록 중 가입, 등록 중 아이디 로그인(새로 고침 후 이어서), 로그인한 폰에서 다음 물고기까지. 버튼이 화면 안에 있고 다른 것에 가려지지 않는지도 확인 (새 가짜 서버에서 실행) |
| 여러 사람 실시간 | `web/live.js` | 브라우저 여러 개로 전체 채팅(실시간 도착, 링크·전화번호 거부, 욕설 가림, 신고, 운영자 숨기기·금지), 친구 1:1(안 읽은 수, 알림, 폰 알림 요청, 남은 못 읽음), 찌릿 라이브(물가에서 현장 낚시, 물 위만 조준, 다른 사람에게 내 찌가 보임, 미리 챔질하면 놓침, 입질→챔질→감기→랜딩, 잡은 고기 카드·포인트·도감·주간 순위, 다른 사람 화면의 실시간 조황, 내 찌 숨기기, 폰에서 위치 없이 원정 낚시와 하루 횟수), 게시판 댓글 수정·내 글·운영자 완전 삭제, 회원 탈퇴(아이디 유무, 틀린 비밀번호, 운영자 불가, 서버 준비 전 안내), 폰 화면 (새 가짜 서버에서 실행) |
| 포인트·루어 상점 | `web/shop.js` | 지갑, 지난주 상금 도착(한 번만 축하), 낚시점 칸(루어·낚싯대·릴·찌, 로고는 시그니처 2개씩만)·사기(두 번 눌러 확인)·장착(캐릭터 낚싯대·릴, 공원 찌·루어에 표시와 도움), 운영자 포인트 지급, 결제 창 계좌 송금(켤 때만, 폰은 토스 자동 입력), 폰 화면, 업데이트 전 서버 |

- 필요한 것: Node 18+, Python 3, Playwright + Chromium. 처음 실행하면 `npm install`로 PGlite·Leaflet·QR 라이브러리를 받습니다.
- 화면 사진과 결과는 `tests/out/`에 남습니다 (저장소에는 올리지 않음).
- `web/phone.js home:-:01_home rank:-:02_rank`처럼 실행하면 휴대폰 크기 화면 사진을 찍습니다 (웹 점검 서버가 켜져 있어야 함: `node web/server.js`).
- `fixtures/`의 사진은 테스트용으로 만든 그림입니다.
- 새 기능을 넣으면 같은 파일에 확인 항목을 추가합니다. 서버 규칙을 바꾸면 `db/rules.test.mjs`에, 화면 기능은 `web/run.js`에 추가합니다.
