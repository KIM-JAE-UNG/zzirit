# 찌릿 ZZIRIT

사진 한 장으로 어종을 찾고, 전 세계 낚시꾼과 겨루는 낚시 리그.

- 웹사이트: https://kim-jae-ung.github.io/zzirit/
- 문의: 카카오톡 (앱의 고객센터 화면)

## 기능

- AI 어종 판별 (BETA, 틀릴 수 있음): "이 물고기가 맞나요?" 확인, 틀리면 학습시키기. 물고기가 없는 사진은 등록되지 않음
- AI 자동 검토: 확인이 필요한 조과는 AI가 몇 분 안에 다시 보고 승인·반려, 애매한 것만 '보류'로 운영자에게. 종별 기록의 1.3배를 넘는 길이는 서버가 바로 거부
- AI 한도가 끝나면 무료 모드: 구글 렌즈로 직접 찾아보고 고르기 (자동 검토 후 반영)
- 독 있는 어종 표시, 금어기·금지체장 경고, 오늘의 물때
- 위성 지도: 바다 이름, 월·계절별 어종 확률, 이용자 조과가 쌓일수록 정확해짐
- 랭킹: 한국 · 동아시아 · 전 세계 · 친구 · 팀
- 커뮤니티 게시판 (조황·질문·자유, 댓글·좋아요·신고), 팀 만들기·가입·팀 랭킹
- 나만의 캐릭터 (머리·눈·입·모자·옷·소품·낚싯대), 프로필 사진 업로드
- 레벨: 조과로 경험치를 얻고, 레벨이 오르면 꾸미기 아이템과 캐릭터 파츠가 열림
- 나의 바다 꾸미기, 과거 조과 등록 (무료)
- 오늘의 낚시 소식: 찌릿 속보(이용자 대물·희귀·첫 기록) + 세계 낚시 뉴스 (제목·출처·링크만)
- 회원가입·로그인 (이메일 없이 아이디·비밀번호): 처음 오면 가입 창이 뜸. 가입해도 그 기기 기록은 그대로, 다른 기기에서 로그인하면 그 기기 기록이 계정으로 합쳐짐. 8자리 코드·QR로 기기를 잇는 방법도 있음
- 계정 복구: 브라우저 기록을 지워 계정을 잃은 사람에게 운영자가 30분짜리 복구 코드를 만들어 줌. 로그인이 잠깐 끊겨도 저장해 둔 로그인으로 다시 이어서 빈 새 계정이 생기지 않음
- 낚시 포인트: 자주 가는 곳·잘 무는 어종·메모를 기록. 기본은 나만 보기, 공유하면 모두의 목록과 지도에 표시 (운영자가 가릴 수 있음)
- 유료는 2개뿐: 황금 세트, 용궁 테마 (각 500원) + 개발자 후원 500원. 토스아이디(금액 자동 입력, 받기 없이 입금)·카카오페이 송금코드, 계좌번호는 공개하지 않음
- 결제는 운영자가 입금을 확인해야 적용 ("보냈어요"만으로는 적용 안 됨). 주문은 수정 불가, 확인 대기 주문은 최대 3개
- 찌릿이란? 페이지: 이름·로고의 뜻, 브랜드가 하는 일
- 조과 카드: "자랑하기"로 카카오톡·인스타그램에 올릴 이미지 만들기 (정확한 위치는 넣지 않음)
- 운영자 공지: 관리자 화면에서 올리면 홈과 게시판 맨 위에 표시
- 이름 옆 레벨 표시 (게시판·랭킹·친구·팀), 운영자처럼 보이는 닉네임 금지
- 사진은 한 번 받으면 기기에 저장해 다시 받지 않음
- 로그아웃: 설정의 계정 카드, 이름 옆 버튼(PC), 더보기 메뉴(폰). 아이디나 연결된 기기가 없으면 돌아올 방법이 없으니 먼저 아이디를 만들게 안내. 로그아웃하면 로그인 창이 바로 뜸
- 알림 (종 버튼): 내 글의 댓글·좋아요, 친구 요청·수락, 조과 검토 결과, 팀 가입 신청, 운영자 공지, 입금 확인, 새 업적. 서버에 따로 저장하지 않고 기기에서 만듦
- 바다 날씨: 홈과 낚시 포인트에서 바람·돌풍·파도·수온·비 확률과 대략적인 출조 판단 (Open-Meteo, 30분 저장, 비상업 무료. 출조 전 기상청 특보 확인 안내). 관리자 화면에서 끌 수 있음
- 오늘의 출조 점수: 날씨 40 + 물때 30(중간 물살일수록) + 제철 30(지역 어종이 가장 활발한 달일수록). 바람·파도가 강하거나 천둥이면 30점 이하. 민물은 물때 제외. 해 뜰 무렵·해 질 무렵 시간과 지금 잘 잡히는 어종
- 내 조과 통계: 달마다·시간대별 조과, 많이 잡은 어종, 자주 쓴 미끼, 어종별 최고 기록 (모든 그래프에 숫자 표)
- 주간 대물 대회: 월~일(한국 시간), 어종 보통 크기 대비 가장 큰 물고기가 1위. 지난 조과 등록은 제외, 주가 끝난 다음 날까지 올린 조과 포함 후 확정. 3위 안이면 알림과 업적
- 폰 알림 (Web Push): 종 버튼·설정에서 기기마다 켬. 댓글, 친구 요청·수락, 팀 가입 신청, 공지, 입금 확인, 조과 검토 결과. 서버가 실제로 일어난 일인지 확인하고 한 번만, 보내는 사람당 10분에 30개까지. 아이폰은 홈 화면 앱에서만. 로그아웃하면 그 기기는 꺼짐
- 업적 20가지: 나의 바다 '업적' 탭. 확인된 조과로만 채워짐 (첫 조과, 어종 수집, 방생, 대물, 밤낚시, 이달의 어종 등)
- 메뉴: 홈 + 4개 묶음(낚시하기·내 기록·커뮤니티·도움·설정). 누르면 펼쳐지고, 지금 화면의 묶음은 열려 있음. 폰은 더보기 시트에서 한 번에 하나씩
- 등록 중에 아이디로 로그인해도(계정을 바꾸느라 새로 고침) 하던 조과 등록이 그대로 이어짐 (사진·AI 결과·고른 어종, 이 탭에서 30분)
- 앱으로 설치: 홈 화면에 추가 (안드로이드·PC는 한 번에, 아이폰은 공유 → 홈 화면에 추가 안내, 카카오톡 안에서는 다른 브라우저로 열기). 인터넷이 끊겨도 마지막으로 받은 화면이 열림 (`sw.js`)
- 갯바위 공원 (웹사이트): 접속한 사람들이 바닷가 공원에서 만남. 누르면 걸어가고(물은 돌아서), 말하면 머리 위 말풍선(전체 채팅과 같음), 감정 표현, 포인트 7곳에서 낚시 미니게임(찌가 들어가면 챔질, 줄 긴장을 조절하며 감기), 사람을 누르면 60초 낚시 대결·1:1 대화·친구 신청. 대결은 둘이 같은 바다(같은 물고기 순서)에서 점수 = 길이 ÷ 어종 보통 크기. 낚시점(이달의 어종·미끼), 게시판(주간 대회), 등대(바다 날씨), 계측대(지금 공원 최고 기록), 모닥불, 한국 시간에 맞춘 낮·저녁·밤. 공원 기록은 재미용(랭킹과 무관). 공원 하나에 15명, 넘으면 다음 공원
- 실시간 채팅 (웹사이트): 전체 채팅(최근 3일 보임, 30일 뒤 삭제, 링크·전화번호 거부, 너무 빠르면 잠깐 막힘, 욕설 가림, 신고 → 운영자 문의함)과 친구끼리 1:1 대화(앱에서는 두 사람만 봄, 안 읽은 수 표시, 알림·폰 알림은 내용 없이). 운영자는 메시지 숨기기·채팅 금지(10분·1시간·하루·풀기)
- 게시판: 내 글·댓글 수정·삭제(수정하면 '수정됨'), '내 글'만 보기, 운영자는 숨기기와 완전 삭제
- 회원 탈퇴: 설정 → 회원 탈퇴. 「탈퇴」 입력 후 진행, 아이디가 있으면 비밀번호 확인. 계정과 연결된 모든 기기, 조과·사진·포인트·글·댓글·채팅·1:1·친구·팀·아이디·폰 알림이 바로 지워지고 이 기기도 처음 상태로. 운영자 계정은 여기서 탈퇴 불가

## 구조

```
index.html        웹 버전 (GitHub Pages). build.py가 만듦
artifact.html     Claude 아티팩트 버전. build.py가 만듦
src/              앱 소스
  core.js         상태, 상점·레벨, 공통 함수
  views.js        화면 (홈, 판별, 바다, 랭킹, 관리자 등)
  char.js         캐릭터 만들기
  scene.js        나의 바다 장면 (캔버스)
  community.js    게시판, 팀
  news.js         오늘의 낚시 소식
  points.js       낚시 포인트
  notify.js       알림
  weather.js      바다 날씨 (Open-Meteo)
  badges.js       업적
  stats.js        내 조과 통계
  contest.js      주간 대물 대회
  push.js         폰 알림 켜기·끄기
  chat.js         실시간 채팅 (전체 · 1:1)
  park.js         갯바위 공원 (지도·걷기·낚시 게임·대결, Supabase Realtime 접속자·방송)
  rt-supabase.js  웹 버전에서 Supabase를 앱 저장소로 연결 (계정 연결·채팅·공원 채널 포함)
sw.js             웹 앱 설치·오프라인용 (화면은 항상 인터넷에서 먼저 받고, 끊겼을 때만 저장본)
geo/              위성사진·해안선·도시 데이터
supabase/
  migrations/     DB 표, 접근 규칙, 점수·AI 검사·유료 아이템 서버 확인

  functions/news/ 낚시 뉴스 모으기 (6시간마다)
  functions/review/ AI 자동 검토 (5분마다 + 조과 등록 직후), 결과를 폰 알림으로
  functions/push/ 폰 알림 보내기 (암호화 RFC 8291, VAPID 키는 서버가 한 번 만들어 Vault에 보관)
  migrations/0007b 아이디·복구 코드·주문 규칙·검토 대기열·낚시 포인트 (기록을 지우지 않음, 적용됨)
  migrations/0008~9 결제 규칙 강화·전체 초기화(끝나면 공지 자동 등록)·계정 삭제 (기록을 지우므로 운영자가 직접 실행)
  migrations/0010 폰 알림: 구독·검증·한 번만 보내기 (기록을 지우지 않음, 적용됨)
  migrations/0011 예전 SQL 파일을 다시 실행해 되돌아간 아이디·검토 함수를 최신으로 (적용됨)
  migrations/0012 기기 연결 코드 함수 최신으로·정리·초기화 시각 기록 (운영자가 SQL 편집기에서 실행)
  migrations/0013 실시간 채팅·1:1·채팅 금지·게시판 완전 삭제·1:1 폰 알림 (적용됨)
  migrations/0014 회원 탈퇴 함수 (계정을 지우므로 운영자가 SQL 편집기에서 실행)
  migrations/0015 30일 지난 전체 채팅 정리 (매일 새벽, 운영자가 SQL 편집기에서 실행)
tests/            자동 점검 (서버 규칙·웹사이트·Claude 페이지·폰 조과 등록·여러 사람 실시간)
```

## 빌드

```
python3 build.py
```

## 점검

```
bash tests/run-all.sh
```

서버 규칙(PGlite), 웹사이트(가짜 Supabase), Claude 페이지(가짜 런타임)를 실제 브라우저로 한 번에 확인합니다. 자세한 내용은 `tests/README.md`.

앱 이름은 `build.py`의 `BRAND` 한 곳만 바꾸면 전체가 바뀝니다.

## 서버 (Supabase)

- 방문자는 가입 없이 익명 계정으로 바로 참여합니다 (Authentication → Providers → Anonymous sign-ins).
- 각자 자기 기록만 고칠 수 있고, 점수·AI 검사 결과·유료 아이템은 서버가 다시 확인합니다.
- 정확한 낚시 위치는 본인만 보고, 공개 데이터에는 약 25 km 격자만 남습니다.
- AI 사진 판별은 Edge Function `ai`가 처리합니다. Edge Function Secrets에 `GEMINI_API_KEY`(Google AI Studio, 무료 등급)를 넣으면 Gemini를, 없으면 `ANTHROPIC_API_KEY`로 Claude를 씁니다.
- Gemini 무료 등급은 보낸 내용이 Google 서비스 개선에 쓰일 수 있어, 앱의 개인정보 안내에 적어 두었습니다.
- AI 사용량 기본값: 하루 1인 사진 20회·글 30회, 앱 전체 사진 300회·글 600회. Secrets의 `AI_USER_IMAGES`, `AI_DAILY_IMAGES`, `AI_USER_TEXT`, `AI_DAILY_TEXT`로 바꿀 수 있습니다.
- 뉴스는 `pg_cron`이 6시간마다 `news` 함수를 부릅니다 (함수는 1시간에 한 번까지만 새로 모음).
- 채팅과 공원은 Supabase Realtime을 씁니다. 무료 요금제 한도(동시 접속 200, 초당 메시지 100, 월 200만 메시지)에 맞춰 공원은 누를 때 한 번만 보내고(각 기기가 걸음을 그림), 접속자 정보는 멈췄을 때만 갱신, 전체 채팅은 채팅 화면이나 공원에 있을 때만 받습니다.

## 관리자

사이트 주소 뒤에 `#claim`을 붙여 열고 관리자 코드를 넣으면 그 브라우저가 관리자로 등록됩니다. 관리자 화면에서 입금 확인·취소, 보류된 조과 검토, 신고 처리, 프로필 사진 가리기, 공지, 사용자 검색(닉네임·아이디), 계정 복구 코드, 계정 삭제(지금 쓰는 계정 제외), 아이디 비밀번호 초기화, 공유 포인트 가리기를 할 수 있습니다. 채팅에서는 메시지의 ⋯ 버튼으로 숨기기·채팅 금지, 게시판 글·댓글에서는 숨기기·완전 삭제를 할 수 있습니다.
