# 찌릿 ZZIRIT

사진 한 장으로 어종을 찾고, 전 세계 낚시꾼과 겨루는 낚시 리그.

- 웹사이트: https://kim-jae-ung.github.io/zzirit/
- 문의: 카카오톡 (앱의 고객센터 화면)

## 기능

- AI 어종 판별 (BETA, 틀릴 수 있음): "이 물고기가 맞나요?" 확인, 틀리면 학습시키기. 물고기가 없는 사진은 등록되지 않음
- 전설의 괴어 레이드: 2시간마다 유명한 바다에 거대한 전설의 괴어가 20분 동안 나타나고, 어디서든 모두 함께 챔질해 잡음. 사람이 늘수록 괴어도 강해지고, 처치하면 기여도만큼 포인트, MVP는 도감에. 실시간으로 남의 챔질이 보임
- 나의 낚시 결산: 올해 낚은 고기·가장 큰 고기·단짝 물고기·바빴던 달·낚시 시간·어떤 낚시꾼인지를 이야기 화면으로, 스토리 크기 카드로 공유
- AI 자동 검토: 확인이 필요한 조과는 AI가 몇 분 안에 다시 보고 승인·반려, 애매한 것만 '보류'로 운영자에게. 종별 기록의 1.3배를 넘는 길이는 서버가 바로 거부
- AI 한도가 끝나면 무료 모드: 구글 렌즈로 직접 찾아보고 고르기 (자동 검토 후 반영)
- 독 있는 어종 표시, 금어기·금지체장 경고, 오늘의 물때
- 위성 지도: 바다 이름, 월·계절별 어종 확률, 이용자 조과가 쌓일수록 정확해짐
- 랭킹: 한국 · 동아시아 · 전 세계 · 친구 · 팀
- 커뮤니티 게시판 (조황·질문·자유, 댓글·좋아요·신고), 팀 만들기·가입·팀 랭킹
- 나만의 캐릭터 (머리·눈·입·모자·옷·소품·낚싯대), 프로필 사진 업로드
- 레벨: 조과로 경험치를 얻고, 레벨이 오르면 꾸미기 아이템과 캐릭터 파츠가 열림
- 나의 바다 꾸미기, 과거 조과 등록 (무료)
- 오늘의 낚시 소식: 찌릿 속보(이용자 대물·희귀·첫 기록) + 세계 낚시 뉴스 (제목·출처·링크만)
- 회원가입·로그인 (이메일 없이 아이디·비밀번호): 처음 오면 가입 창이 뜸. 가입해도 그 기기 기록은 그대로, 다른 기기에서 로그인하면 그 기기 기록이 계정으로 합쳐짐. 8자리 코드·QR로 기기를 잇는 방법도 있음
- 계정 복구: 브라우저 기록을 지워 계정을 잃은 사람에게 운영자가 30분짜리 복구 코드를 만들어 줌. 로그인이 잠깐 끊겨도 저장해 둔 로그인으로 다시 이어서 빈 새 계정이 생기지 않음
- 낚시 포인트: 자주 가는 곳·잘 무는 어종·메모를 기록. 기본은 나만 보기, 공유하면 모두의 목록과 지도에 표시 (운영자가 가릴 수 있음)
- 유료는 2개뿐: 황금 세트, 용궁 테마 (각 500원) + 개발자 후원 500원. 토스아이디(금액 자동 입력, 받기 없이 입금)·카카오페이 송금코드, 계좌번호는 공개하지 않음
- 결제는 운영자가 입금을 확인해야 적용 ("보냈어요"만으로는 적용 안 됨). 주문은 수정 불가, 확인 대기 주문은 최대 3개
- 찌릿이란? 페이지: 이름·로고의 뜻, 브랜드가 하는 일
- 조과 카드: "자랑하기"로 카카오톡·인스타그램에 올릴 이미지 만들기 (정확한 위치는 넣지 않음)
- 운영자 공지: 관리자 화면에서 올리면 홈과 게시판 맨 위에 표시
- 이름 옆 레벨 표시 (게시판·랭킹·친구·팀), 운영자처럼 보이는 닉네임 금지
- 사진은 한 번 받으면 기기에 저장해 다시 받지 않음
- 로그아웃: 설정의 계정 카드, 이름 옆 버튼(PC), 더보기 메뉴(폰). 아이디나 연결된 기기가 없으면 돌아올 방법이 없으니 먼저 아이디를 만들게 안내. 로그아웃하면 로그인 창이 바로 뜸
- 알림 (종 버튼): 내 글의 댓글·좋아요, 친구 요청·수락, 조과 검토 결과, 팀 가입 신청, 운영자 공지, 입금 확인, 새 업적. 서버에 따로 저장하지 않고 기기에서 만듦
- 바다 날씨: 홈과 낚시 포인트에서 바람·돌풍·파도·수온·비 확률과 대략적인 출조 판단 (Open-Meteo, 30분 저장, 비상업 무료. 출조 전 기상청 특보 확인 안내). 관리자 화면에서 끌 수 있음
- 오늘의 출조 점수: 날씨 40 + 물때 30(중간 물살일수록) + 제철 30(지역 어종이 가장 활발한 달일수록). 바람·파도가 강하거나 천둥이면 30점 이하. 민물은 물때 제외. 해 뜰 무렵·해 질 무렵 시간과 지금 잘 잡히는 어종
  - 화면은 한눈에: 점수 옆에 한 줄 결론(예: 「아주 좋아요 — 바람·파도 잔잔 · 물때 무난 · 제철 물고기 많음」), 바람·파도·날씨·물때 네 칸을 쉬운 말과 색(초록 좋음·노랑 주의·빨강 위험)으로, 좋은 시간(해 뜰·질 무렵, 지금이면 「지금」 표시)과 잘 잡히는 물고기. 점수 계산 막대는 「점수는 어떻게 매기나요?」 안에. 바람·파도가 '주의'면 결론은 '보통' 이하
- 내 조과 통계: 달마다·시간대별 조과, 많이 잡은 어종, 자주 쓴 미끼, 어종별 최고 기록 (모든 그래프에 숫자 표)
- 주간 대물 대회: 월~일(한국 시간), 어종 보통 크기 대비 가장 큰 물고기가 1위. 지난 조과 등록은 제외, 주가 끝난 다음 날까지 올린 조과 포함 후 확정. 3위 안이면 알림과 업적
- 폰 알림 (Web Push): 종 버튼·설정에서 기기마다 켬. 댓글, 친구 요청·수락, 팀 가입 신청, 공지, 입금 확인, 조과 검토 결과. 서버가 실제로 일어난 일인지 확인하고 한 번만, 보내는 사람당 10분에 30개까지. 아이폰은 홈 화면 앱에서만. 로그아웃하면 그 기기는 꺼짐 아침 알림(하루 한 번, 오전 7시 반~9시): 살림망 고기가 ×1.2 이상으로 비싼 날·사리가 시작되는 날·주간 라이브 상금을 받은 날에만, 하나로 묶어 한 번. 세 가지는 각각 끌 수 있음(계정마다 서버에 저장). 같은 소식은 앱의 알림 종에도 나옴.
- 업적 20가지: 나의 바다 '업적' 탭. 확인된 조과로만 채워짐 (첫 조과, 어종 수집, 방생, 대물, 밤낚시, 이달의 어종 등)
- 메뉴: 홈 + 4개 묶음(낚시하기·내 기록·커뮤니티·도움·설정). 누르면 펼쳐지고, 지금 화면의 묶음은 열려 있음. 폰은 더보기 시트에서 한 번에 하나씩
- 등록 중에 아이디로 로그인해도(계정을 바꾸느라 새로 고침) 하던 조과 등록이 그대로 이어짐 (사진·AI 결과·고른 어종, 이 탭에서 30분)
- 앱으로 설치: 홈 화면에 추가 (안드로이드·PC는 한 번에, 아이폰은 공유 → 홈 화면에 추가 안내, 카카오톡 안에서는 다른 브라우저로 열기). 인터넷이 끊겨도 마지막으로 받은 화면이 열리고 진짜 앱이 시작됨(로그인 라이브러리·글꼴은 기기에 보관, 위에 「인터넷이 끊겼어요」 줄, 돌아오면 「새로 불러오기」). 지도 부품은 첫 화면에서 빠지고 지도를 열 때만 받음 (`sw.js`, `net.js`)
- 찌릿 라이브 (웹사이트, 탭 「라이브」): 실제 지도 위에서 하는 실시간 낚시 게임 하나. 건물이 입체로 보이는 지도(MapLibre GL + OpenStreetMap 벡터 타일, 낮·해 질 녘·밤 3가지 색)에 내 위치가 뜨고, 물(바다·강·호수)이 낚싯대 비거리 안에 있으면 그 물에 바로 캐스팅(현장 낚시). 멀리 있어도 하루 5번은 물가를 골라 원정 낚시(포인트 절반, 전설급은 안 나옴). 입질이 오면 번개와 함께 폰이 떨리고(찌릿!), 챔질 → 줄 긴장을 조절하며 감기 → 잡은 고기 카드. 고기는 그 물·그 달에 실제로 사는 어종에서 나오고, 물때·해 뜰/질 무렵·10분마다 옮겨 다니는 어군에 따라 입질이 달라짐. 다른 사람의 찌·입질 번개·방금 잡은 고기가 지도에 실시간으로 보임(내 찌 숨기기 가능). 도감, 주간 순위(가장 좋은 5마리 합계), 포인트는 서버가 관리. 내 위치는 서버로 보내지 않음(찌가 떨어진 물의 약 110m 칸만) 내 캐릭터(프로필에서 꾸민 모습)가 지도 위에 온몸으로 서서 걷고, 던지고, 입질에 놀라고, 릴을 감음. 카메라는 낚시꾼 어깨 뒤에서 옆으로 보고, 시야를 가리는 건물은 낮아짐. 친구랑 같이: 「친구 부르기」 링크(물가의 대강 자리 약 100m와 닉네임만 담김)를 받은 친구는 같은 물가로 바로 와서 서고, 친구 찌는 하늘색 이름표, 위쪽에 '친구 N' 표시. 누가 고기를 잡으면 소식 줄의 「박수」로 한 번 응원(받는 사람 화면에 'OO님이 박수를 보냈어요!').
- 찌릿 포인트·낚시점 (웹사이트): 라이브에서 낚은 고기는 살림망(30마리)에 담기고, 팔면 등급별 1~30P에 그날 시세(×0.8~×1.4, 한국 시간 자정에 바뀜)를 곱해 받음(하루 80P어치까지 판매, 새 어종은 바로 +10P), 주간 순위 1·2·3등 300·200·100P와 1등 황금 번개 루어 (한국 시간 월요일 0시 정산). 포인트로 루어·낚싯대·릴·찌를 사서 장착하면 캐릭터와 라이브 낚시에 나타남: 낚싯대는 비거리(60→100m), 릴은 감기, 찌는 챔질 여유, 루어는 대물 확률. 칸마다 찌릿 로고가 들어간 시그니처 2개(800~1,200P). 가격·지갑·구매는 서버가 관리
- 오늘의 미션·연속 출석 (웹사이트): 한국 날짜마다 라이브 미션 3개(고기 낚기, 귀한 고기·대물·원정·바다/민물 고기, 팔기·놓아주기 중에서 서버가 고름). 서버가 그날 기록으로 세고, 다 한 미션은 「받기」로 10~20P, 3개 모두 +20P (한 번씩만). 하루 한 번 들어오면 출석(5P, 7일째마다 30P), 하루라도 빠지면 1일부터. 홈의 「오늘의 미션」 카드와 라이브의 과녁 버튼
- 라이브 지도의 진짜 날씨 (웹사이트): 그 지역 날씨(Open-Meteo, 약 10km로 어림한 자리만 보냄)대로 비·눈·안개·바람·천둥이 지도 위에 보이고, 바람이 세면 찌가 더 흔들림. 위의 날씨 표시(예: 「비 11° 입질 ▲」)를 누르면 이유를 알려 줌. 흐림·비·안개는 입질이 조금 빠르고(×0.88~0.95), 눈·바람·천둥은 조금 느림(×1.05~1.2). 숫자는 서버가 정함. 움직임 줄이기 설정이면 빗방울 없이 색만
- 캐릭터 감정 표현 (웹사이트): 라이브의 웃는 얼굴 버튼으로 내 캐릭터가 손 흔들기(무료)·인사·춤·찌릿 댄스(시그니처)를 함. 같은 물가 사람에게는 그 사람 찌 위에 말풍선(찌가 없으면 소식 줄)으로 보임. 보내는 건 누가·어떤 동작인지뿐, 위치는 보내지 않음. 「내 찌 숨기기」를 켜면 나만 봄. 인사 150P·춤 300P·찌릿 댄스 800P는 낚시점 「감정 표현」 칸에서 포인트로 사고(가격·보유는 서버), 내 캐릭터가 움직이는 모습으로 미리 볼 수 있음
- 잡은 고기 자랑 카드 (웹사이트): 라이브에서 고기를 낚으면 결과 카드의 「자랑하기」로 인스타그램·카카오톡 스토리 크기(1080×1920) 그림을 만듦. 내 캐릭터가 고기를 든 모습, 어종·길이·등급, 도감 첫 등록·대물·현장·이번 주 순위, 바다 이름(민물은 지역)·날씨·닉네임. 기기 안에서 그리고, 정확한 자리는 넣지 않음. 폰은 바로 공유, PC는 저장 버튼
- 도감 세트와 칭호 (웹사이트): 라이브 「도감·순위」의 「세트」 칸에 세트 12개(갯바위 삼총사·서해 손맛·문어·오징어·가시·독 조심·우리 강·저수지·열대 바다·세계의 강·전설 수집, 봄·여름·가을·겨울). 세트의 고기를 서로 다르게 정해진 수만큼 모으면 「받기」로 50~200P(한 번)와 칭호. 계절 세트는 그 달(한국 날짜)에 낚은 고기만 셈. 칭호는 하나를 골라 달고, 주간 순위 이름 옆과 자랑 카드에 보임. 세기·지급·칭호는 서버가 관리(0026)
- 실시간 채팅 (웹사이트): 전체 채팅(최근 3일 보임, 30일 뒤 삭제, 링크·전화번호 거부, 너무 빠르면 잠깐 막힘, 욕설 가림, 신고 → 운영자 문의함)과 친구끼리 1:1 대화(앱에서는 두 사람만 봄, 안 읽은 수 표시, 알림·폰 알림은 내용 없이). 운영자는 메시지 숨기기·채팅 금지(10분·1시간·하루·풀기)
- 게시판: 내 글·댓글 수정·삭제(수정하면 '수정됨'), '내 글'만 보기, 운영자는 숨기기와 완전 삭제
- 회원 탈퇴: 설정 → 회원 탈퇴. 「탈퇴」 입력 후 진행, 아이디가 있으면 비밀번호 확인. 계정과 연결된 모든 기기, 조과·사진·포인트·글·댓글·채팅·1:1·친구·팀·아이디·폰 알림이 바로 지워지고 이 기기도 처음 상태로. 운영자 계정은 여기서 탈퇴 불가

## 서버 (Supabase)

- 방문자는 가입 없이 익명 계정으로 바로 참여합니다 (Authentication → Providers → Anonymous sign-ins).
- 각자 자기 기록만 고칠 수 있고, 점수·AI 검사 결과·유료 아이템은 서버가 다시 확인합니다.
- 정확한 낚시 위치는 본인만 보고, 공개 데이터에는 약 25 km 격자만 남습니다.
- AI 사진 판별은 Edge Function `ai`가 처리합니다. Edge Function Secrets에 `GEMINI_API_KEY`(Google AI Studio, 무료 등급)를 넣으면 Gemini를, 없으면 `ANTHROPIC_API_KEY`로 Claude를 씁니다.
- Gemini 무료 등급은 보낸 내용이 Google 서비스 개선에 쓰일 수 있어, 앱의 개인정보 안내에 적어 두었습니다.
- AI 사용량 기본값: 하루 1인 사진 20회·글 30회, 앱 전체 사진 300회·글 600회. Secrets의 `AI_USER_IMAGES`, `AI_DAILY_IMAGES`, `AI_USER_TEXT`, `AI_DAILY_TEXT`로 바꿀 수 있습니다.
- 뉴스는 `pg_cron`이 6시간마다 `news` 함수를 부릅니다 (함수는 1시간에 한 번까지만 새로 모음).
- 채팅과 라이브는 Supabase Realtime을 씁니다. 무료 요금제 한도(동시 접속 200, 초당 메시지 100, 월 200만 메시지)에 맞춰 라이브는 찌를 던질 때·입질·랜딩 때만 보내고(약 20km 구역마다 채널 하나), 화면을 떠나면 채널에서 나갑니다.

## 관리자

사이트 주소 뒤에 `#claim`을 붙여 열고 관리자 코드를 넣으면 그 브라우저가 관리자로 등록됩니다. 관리자 화면에서 입금 확인·취소, 보류된 조과 검토, 신고 처리, 프로필 사진 가리기, 공지, 사용자 검색(닉네임·아이디), 계정 복구 코드, 계정 삭제(지금 쓰는 계정 제외), 아이디 비밀번호 초기화, 공유 포인트 가리기를 할 수 있습니다. 채팅에서는 메시지의 ⋯ 버튼으로 숨기기·채팅 금지, 게시판 글·댓글에서는 숨기기·완전 삭제를 할 수 있습니다.
